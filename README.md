# Job Portal Web App (Symfony)

This is a job portal web application built using Symfony. Users can register, log in, post jobs searching, and apply.

## Features
- Admin and user roles
- Job listing and search
- Secure login system

## Tech Stack
- Symfony PHP Framework
- MySQL Database
- Twig templating

## How to Run Locally
1. Clone the repo
2. Run `composer install`
3. Create a `.env.local` file with DB credentials
4. Run `symfony server:start`
